Security

We are asking you to trust us with your gaps

So here is exactly how the product is built.

Isolation in the database

Every table enforces tenant isolation with row-level security keyed on company membership — not in application code, where a bug becomes a breach.

Evidence is never public

Files live in a private bucket. Downloads use short-lived signed links, and every access is recorded in an append-only log.

Credentials you cannot read back

Integration tokens are stored where the application's own database role has no read access at all. They are only ever sent back to the provider they came from.
